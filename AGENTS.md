Antes de realizar cualquier cambio importante de estructura debes consultarme

Ante la duda de la estructura, tablas, filas, campos dentro de la base de datos debes entregarme la query para la correspondiente consulta, esta las realizare de forma manual y te entregare el resultado para tu comprension.

Siempre Actualiza la DOCUMENTACION.md del proyecto con los ultimos cambios tanto de front-end como de back-end o de base de datos 

Si utilizas alguna terminal para ejecutar algo automatizado utiliza la Git BASH para evitar problemas de polica de powershell

INFORMACION TECNICA

El proyecto utilizara un Stack de NextJs, React, Typescript, TailwindCSS y PostgreSQL.

Sera alojado en una base de datos gratuita en SUPABASE.

TODOS LOS CAMBIOS EN LA ESTRUCTURA SQL QUE SE VAYAN HACIENDO DEBEN PERMANECER ACTULIZADOS,
IREMOS CREANDO LAS QUERYS EN UNA CARPETA SQL PARA Tener EL REGISTRO COMPLETO DE TODAS LAS TABLAS, FILAS Y CAMPOS DENTRO DE ELLAS.
PARA POSTERIORMENTE EJECUTARLO EN SUPABASE.

EL FRONT-END SERA ALOJADO EN VERCEL

DEBES OPTIMIZAR AL MAXIMO CADA CONSULTA QUE PUEDA REALIZAR EL SISTEMA YA QUE LA BASE DE DATOS SERA LA GRATUITA.
Por lo tanto debemos cuidar el "Egress, CPU y Storage" de Supabase.

NO USAR EMOJIS

Vamos a priorizar las buenas practicas, tanto para estructura y seguridad del sistema en general.
